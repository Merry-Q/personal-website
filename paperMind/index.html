Case 02 · paperMind

读完一篇论文，而不是读完一段摘要。

专业 PDF 的价值在论证、机制、条件和局限。paperMind 用完整交互讲解接住阅读，让每句补充都能回到原文。

页边笔记

有引用，不等于站得住。

核验不足的回答禁止写入页面。理解不打分，沉淀由读者自己确认。

The Problem

文献一多，综述就变成摘要堆砌。

研究生和跨领域研究者真正卡住的，往往不是「这段英文看不懂」，而是机制、公式、图表和适用条件在脑子里对不上。聊天式问答会把论文压成顺口的段落；测验分数又会假装理解已经发生。

外部知识会悄悄冒充原文。教学演示会看起来像实验复现。版本差异会被模型「帮忙改对」。

现状

  • chat通用问答框无法保住论证主线
  • quiz掌握评分替代不了能回查的理解
  • broken_image图表与扫描页被当成纯文本处理

The Solution

一条主线，三种来源，两次确认。

完整交互讲解

上传后沿问题、方法、机制、证据与局限读下去。演示按内容选择，不强加滑块。讲解由文本决定，不为读者预设「小白 / 高阶」身份。

来源三分

论文内容、外部知识、教学加工分开标注。类比和自建数值不能写成作者实验。

menu_book

引用回查

点击讲解回到原句、原页或框选区域。

psychology

锚定 Copilot

深度问题先出研究计划，确认后再取证。

layers

两套沉淀

加入页面与加入概念库分开，均可撤回。

The Process

模型按任务换班，产品按阶段验收。

解析

PDF → 正文与锚点

文字进入计划；扫描页走 OCR，图表页走视觉预读。默认 OCR 30 页、视觉预读 2 页，其余页可主动提问。双栏顺序是启发式，读错时保留原页。

生成

规划与分章讲解

qwen3.5-plus 做全文计划与连续讲解，章节以沙箱页面呈现。生成成功即发布阅读页，失败版本不充当完成页。

对话

取证、核验、写入

Copilot 与核验用 qwen-plus，联网读取有限外部正文。引用契约通过只证明格式关系；不足则提示并禁止加入页面。

评测

十篇真实文献

覆盖注意力机制、RAG、信息论、数字人文、伦理调查与中文长研报。用问题账本记录误报，不以删除失败记录来粉饰。

The Trade-offs

忠实，比流畅更优先。

坚持

  • 无理解测验，避免把点击当成掌握。
  • 原文内部不一致如实列出，不替作者选一个「正确答案」。
  • 较新版本的数字不能覆盖用户上传的那一版。
  • 百分比与百分点、亿与万必须分开说。

代价

  • 长文生成可能数分钟，并产生模型费用。
  • 当前单用户工作台，公开部署尚未做账号隔离。
  • 外部 PDF 默认只读前 12 页，权威来源仍可能取不到。
  • 自动测试不能替代人工学术审查，因此不报告虚假准确率。
