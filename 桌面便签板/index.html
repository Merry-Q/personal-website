Case 03 · 桌面便签板

念头出现的时候，桌面就在。

打开大型笔记会打断手头的事。这个 Windows 应用把记录收成一颗可拖动的日期球：悬停展开，写完继续工作。

The Problem

不是记不住，是记下的成本太高。

tab

切换即中断

为了一句话打开笔记软件，等同步、选笔记本、找文件夹，念头已经散了。

category

事不是一种形状

有的要做，有的还没想清楚，有的只是句子。塞进同一个待办列表，会制造假紧急。

cloud_off

云同步不是前提

碎片记录如果先问登录，产品已经输了。它应该像桌面本身一样本地、安静。

The Solution

三格分类，一层玻璃。

今天必须推进的事。短句即可，完成后划掉，不升级成项目管理。

驻留方式

  • 日期悬浮球可拖动
  • 悬停展开，可钉住面板
  • 展开时取样桌面做毛玻璃
  • 单实例，避免两块板抢桌面

它不是又一个笔记库。它是你每天都会看见的那一层。

The Process

从原型到可以双击打开。

  1. 01

    先写清打断成本

    主路径必须短到几乎无教学：看见球、展开、输入、贴回桌面。安装本身也算流失，所以最终做成便携 exe。

  2. 02

    用三区拆任务

    待办、待定、灵感对应三种心理状态，而不是三种标签颜色。分类发生在写下的瞬间，不要求事后整理。

  3. 03

    从脚本到 Electron

    早期 Python 原型只验证驻留。正式版用 Electron 做窗口、IPC 与打包，毛玻璃借助本机截取桌面区域。

  4. 04

    本地一纸保存

    内容写入 %APPDATA%\桌面便签板\board.json。备份就是复制这个文件。不把便签送进仓库或云端。

The Trade-offs

少做一个功能，是为了少打断一次。

要

  • 热区与按钮不小于 44px，方便点按。
  • 多行灵感用独立编辑，避免 Enter 把没写完的句子提前提交。
  • 毛玻璃只在展开时取样，打开期间不实时刷新，减少占用。
  • 只做 Windows 桌面。网页入口会假装一种它不是的产品。

不要

  • 不做账号、协作和云同步。
  • 不把 AI 整理设成写下的前提。模型可以以后可选，不能挡住那一笔。
  • 不做文件夹树、标签系统和全文搜索的重型结构。
  • 不把 Python 原型继续当正式应用维护。
